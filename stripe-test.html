01 / CONFIGURATION

Relier ton Stripe à Netlify

  1. Ouvre Stripe → Clés API (mode test), puis copie ta clé secrète de test commençant par sk_test_.
  2. Ouvre Netlify → ton projet AvisLink → Project configuration → Environment variables.
  3. Ajoute une variable nommée STRIPE_SECRET_KEY et colle sa valeur uniquement dans Netlify (scope Functions si proposé).
  4. Redéploie ton projet, puis reviens sur cette page et clique sur Vérifier la connexion.

🔒 Ne colle jamais de clé sk_test_ ou sk_live_ dans cette page, dans un fichier HTML, dans un message ChatGPT ou dans un dépôt public. La connexion est faite côté serveur.
